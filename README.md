# readme

A modern, free and open-source GitHub README Maker for developers.

Create a polished README without writing Markdown manually. Add your profile details, choose sections, select skills, preview the result live, then copy or download a ready-to-use `README.md`.

## Features

- Live README preview
- Raw Markdown output
- Copy README to clipboard
- Download `README.md`
- GitHub public profile import
- Skills selector
- Configurable README sections
- Local draft saving with LocalStorage
- Beginner-friendly GitHub README guides
- Responsive developer-focused interface

## Run locally

```bash
npm install
npm run dev
```

Open the local URL shown by Vite in your browser.

## Create a GitHub repository README

1. Sign in to [GitHub](https://github.com).
2. Click the `+` menu and choose **New repository**.
3. Enter a repository name and description.
4. Choose **Public** if you want others to see it.
5. Select **Add a README file**.
6. Click **Create repository**.
7. Open `README.md`, click the pencil icon, and edit it.
8. Add a commit message such as `Improve README`, then click **Commit changes**.

## Use readme to generate yours

1. Open the app and choose **Create README**.
2. Enter your name, GitHub username, title and bio.
3. Select the sections you want to show.
4. Choose your skills and review the live preview.
5. Click **Copy README** or **Download README.md**.
6. Paste the result into your GitHub repository's `README.md` file and commit it.

## GitHub profile README

To create a profile README, create a new public repository with the exact same name as your GitHub username. GitHub will display that repository's README on your profile.
